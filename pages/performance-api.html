Exercises

  1. With the API reachable (?api=http://127.0.0.1:4180), send each endpoint and assert the status line.
  2. Send /api/slow with 400 ms and assert the shown duration is at least 400.
  3. Hit /api/limited until the 429 appears and read Retry-After from the headers list.
  4. Log in, add a product to the cart and check out; assert the order id in the answer.
  5. Send /api/me without logging in and assert the 401.
  6. Compare the "over the wire" size of /api/payload with and without gzip.
  7. Mock the whole API with page.route and test the page without any server.
