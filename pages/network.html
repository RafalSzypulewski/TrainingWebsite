Network

This page makes real fetch() calls to static files (and one POST that a static host cannot answer). Use page.route() to mock, delay, fail or inspect them. The ?delay and ?fail toggles are not used here.

1. List users GET assets/data/api/users.json

No users found.

    The request carries the header X-Practice-Client: pw-lab and the query ?page=1.

    2. Slow request with a timeout GET assets/data/api/slow.json

    Gives up after 3000 ms (change it with ?timeout=500).

    3. Retry on failure GET assets/data/api/flaky.json

    Makes up to 3 attempts, 300 ms apart.

    4. Polling a job GET assets/data/api/status.json

    Polls every 1000 ms until the state is done (change with ?poll=200).

    5. Send feedback POST api/feedback

    No server answers this request. Mock it to see the success path.

    Exercises

    1. Mock users.json with your own data and assert the list.
    2. Fulfill it with [] for the empty state, status 500 for the error, and route.abort() for a network failure.
    3. Delay the response and assert the spinner; then assert the request header and the page query param.
    4. Make slow.json take longer than the timeout (use ?timeout=500).
    5. Fail the flaky endpoint twice, then succeed, and assert "after 3 attempts". Also fail all three.
    6. Return pending twice and then done from the status endpoint.
    7. Mock the POST, assert the request body with postDataJSON(), and assert the success text.
    8. Use page.waitForResponse and page.waitForRequest instead of mocking.
